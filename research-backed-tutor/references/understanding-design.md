# 从认识结论到独立推出结论

每次编写实质教学时使用。本指南把用户提供的 K09 长篇讲解与改进意见转化为可执行要求，补充逐句易懂检查。目标是让学习者知道为何要学、如何从已知走到新结论，并能在变化条件下应用。增加字数、标题数量、公式数量或互动数量都不是目标。

## 选择讲解深度

首次学习用完整讲解建立知识；学完后的摘要用于提取和复习。先给一个具体问题与简短路线，再逐个解决，最后整理结论。保留用户明确声明的基础，陌生处补最小前置；不能因用户提到“傅里叶变换”就说“你已经学过”。已掌握部分可在用户要求下精简，用变式确认是否还需支撑。

主题较大时按能回答的子问题分章，保持前提与结论相邻。篇幅受限时把当前核心机制讲完整，再交代后续章节和覆盖范围；不能把整个主题挤成结论段后声称完整通过。仍遵守主流程对阶段成果的标记。

## 建立一条可重走的解释路径

围绕每个核心机制处理以下问题，按逻辑自然合并，不强制固定小节或给每个细枝末节重复全套。

1. **需要解决什么**：从具体任务、现象或失败出发。说明旧方法能做什么、哪里不足，增加新概念后解决哪一步。
2. **从哪里起步**：把实际用到的旧知识重新接上。给最小例子唤起含义；尚未教会的前置先补，不能只列名称。
3. **具体发生什么**：先说对象、动作、可观察变化，再命名。术语表可辅助，正文仍需解释关系；用另一个陌生词替换原词不算说明。
4. **为什么成立**：从已教规则到当前结论，展示关键中间环节及适用条件。推导同时写明这步要找什么、用什么依据、做什么变换、结果意味着什么。不能把结论改写一遍当作原因。
5. **怎样核验**：完整做一个低复杂度实例。选法、代入、计算、单位、结果解释和合理性检查连在一起；定性主题用材料依据、具体案例及替代解释核对。
6. **条件改变后怎样**：尽量一次改一个因素，先要求预测，再用同一原理核对。比较维度要一致，指出原先哪一步仍成立、哪一步需要重算。适用时用反例揭示边界。
7. **能否自己应用**：先完整示例，再留出一个关键步骤让学习者补全，最后给改变情境或方法选择的独立题。逐渐撤去支撑，避免一直替学习者解题。

章节过渡点明“刚得到什么，它留下哪个问题，下一步为何需要”。标题指向要解决的问题。不要一口气引入多个互相依赖的术语，也不要拆成大量互不连接的一行短句。

## 符号、图形和现实对象互相对照

- 数学：首次定义符号、单位、对象及模型条件；解释变换允许的原因。量纲、极限、特殊值和另一种计算方式用于核验，不能代替核心推导。
- 电路：图中节点、电流和元件标签与方程一致；方程各项对应实际支路。说明连接变化为什么改变模型，而非仅并列两条公式。
- 程序：使用实际输入逐步追踪状态与输出，再解释该机制为何解决问题；不把库函数名当作内部机制的解释。
- 人文与定性主题：区分事件、证据和解释，说明哪些证据支持哪一步推断、有哪些竞争解释；不强造确定的数学因果关系。
- 图与交互：选择能暴露关系的电路图、轨迹、波形或比较图。读图前交代轴、尺度、单位、图例、保持不变的量与观察任务；观察后用原理解释。图文相邻，避免读者来回寻找对应。截图中的文字密集不代表图形教学无效，也不能据此给用户贴“文字型学习者”标签。

用户练习先呈现问题和必要条件，答案另放后文或可展开区域；不能把刚读到的答案立即复述当成独立证据。完成题要求选择或解释关键步骤；迁移题至少改变一个影响推理的条件，单换数字只能检验计算熟练度。自我解释应问“依据什么、何时失效”，而不只问“懂了吗”。复习建议可以安排间隔后的提取任务；未执行的复习只写建议，不写成完成记录，不自动创建提醒。

## 教学深度门槛

在既有范围矩阵中，为每个核心机制追加以下定位信息；详细记录保存在检查产物，正文保持自然。

| 必需证据 | 需要能定位的内容 | 不能通过的情况 |
| --- | --- | --- |
| 问题与起点 | 具体用途、旧知识连接、先教前置的位置 | 上来罗列参数与定义 |
| 因果或证据链 | 已教前提、中间环节、推导依据、结论与条件 | “Q 控制阻尼”只换一种说法 |
| 完整示例 | 从任务到方法、操作、核验及结果含义 | 直接给答案或只列计算结果 |
| 条件对比 | 预测、单因素或清楚标明的变化、核验、失效点 | 比较时偷换定义或多个条件不说明 |
| 撤去支撑 | 补全关键步骤题与独立变式的实际产物及评价 | 只跟抄例题、选择题或换数字 |
| 表征连接 | 用到的图、公式或操作与正文的对应及读法 | 装饰图、孤立公式、失效按钮 |

不适用的表征或数值检查写明学科理由，使用适用的证据；不能用“不适用”取消核心解释、示例和迁移。核验时沿前提到结论检查整段和跨段连接；逐句复述通过但回答不了“为什么这一步会导致下一步”，仍记为理解建构缺口。修复讲解和受影响练习后，按原逐句门槛及稳定轮数重新检查。

## K09 作为回归案例

以下用于检查教学方法，不是要在所有学科套用滤波器例子，也不是零基础完整课程。公式用于核对案例，实际给零基础者讲时须先教符号与运算。

- **级联**：先问增加一级能否改善高频抑制。分别写第一级输出与第二级输入输出关系，再代入得到乘积；不能只说“响应相乘”。
- **加载**：先画两个串联电阻、各节点电容接地的梯形结构。无缓冲时，第一级电流还要流向第二级，列出两节点电流方程，指出新增项来自哪条支路。有缓冲时解释输入电流很小、输出由缓冲级驱动这一模型条件，再比较分母系数。
- **数值核验**：理想电压源、无额外输出负载、等值 R 与 C、零初始条件下，有缓冲的分母是 `1+2sRC+(sRC)^2`；无缓冲为 `1+3sRC+(sRC)^2`。取 `R=1 kΩ, C=10 nF`，在 `ωRC=1` 处幅值比分别为 `1/2` 与 `1/3`。须展示电流方程与计算过程，再解释差异。
- **Q 与阻尼**：从标准二阶低通方程 `y''+(ω₀/Q)y'+ω₀²y=Kω₀²x` 连接到阻尼比 `ζ=1/(2Q)`。如果尚未解释为何该系数刻画衰减，还需用极点、能量或时间响应补桥；不能仅把系数命名为“阻尼项”就宣称原因已讲清。欠阻尼条件 `Q>1/2` 与幅频峰化条件 `Q>1/√2` 分开；保持 `ω₀` 固定，过阻尼区也不能笼统声称“Q 越大所有响应都越慢”。
- **频率**：从 `s=jω` 和复数模长逐步得到幅值公式，再代入 `ω=ω₀` 得 `|H|=KQ`（`K>0,Q>0`）。与相对直流增益的 `-3 dB` 条件 `|H|=K/√2` 比较，说明本模型只有 `Q=1/√2` 时两频率重合。不要把固有频率、峰值频率与截止频率混为一谈。
- **图与选型**：在同一定义和归一化条件下读幅频、相频或群延迟，再把 Butterworth、Bessel、Chebyshev I/II 的差异接到具体幅度误差、波形和阻带指标。不能用三个名称加三个形容词代替选型理由。

再用另一个主题或核心机制的独立变式检验是否会运用这条教学路径，避免只会复刻 K09 的顺序。案例中的理论结果不能宣称硬件实测；手册写得完整也不能证明真实用户已经掌握。

学习科学依据及读取边界见 [learning-science.md](learning-science.md)。这些研究支持教学设计取舍；本指南是任务中的适配，尚不能证明本 skill 的实际教学效果。
