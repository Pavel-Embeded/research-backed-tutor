# 后台零基础初学者闭环

每次实质教学，在把结果交给用户前执行本流程。目的不是让 AI 宣布自己满意，而是用问题、独立产物和可检查证据定位讲解缺口，再修订讲解。

## 初学者状态与隔离

“智商为 0”在此是零前置知识的操作要求，不作真实智力判断或贬低用户。初学者初始只知道明确列出的日常常识、基础语言和任务规则。维护已教知识清单；每个符号、工具操作、定义、前提和方法在使用前必须进入清单。

区分三项任务：导师编写解释；初学者只读解释并提问、输出；核验者依据来源、条件、独立推导、测试和反例评价。初学者不能查看核验者的答案、完整项目范文或完成版关系图；要看的只能是已教内容和当前挑战。

有可用且获准的独立 agent 时，让初学者收到最少的任务材料；没有时在同一 agent 内执行角色分工并声明这不是认知独立的实验。模拟产物必须可见且可核验，但不输出私有思维链、冗长角色辩论或逐 token 的自我思考。

## 每轮都要做的事

1. **逐段质疑**：针对定义、符号、推导、条件、关系、目的、细节和项目步骤提出具体问题。检查“这个词是什么”“为什么这步成立”“前提从哪来”“为什么需要它”“去掉会怎样”“换个条件还成立吗”“为什么不选相邻方法”“如何亲手做到”。不要只写笼统的“我懂了”。
2. **初学者自己输出**：先不看答案，实际写自己的解释、关键推导或操作轨迹、条件与反例、带类型的关系网络，以及与讲解例子不同的新题解答。不能复印原句作为理解证据。
3. **核验产物**：比较定义、约束和来源；检查遗漏、错误边、条件丢失、循环论证、记忆范文和偷用未教知识。适用时运行代码或实验，记录命令、输入、预期、实际和结果；不能运行时写明未运行。
4. **修订教学**：每个错误定位到术语、前置、推导、边界、例子、关系或项目环节。导师直接补充或重写相关讲解；相关引用、例题、图谱和答案一起更新。只改初学者答案不算修订。
5. **换题再检**：使用新输入、新情境、边界条件或反例；不能用刚背过的题作唯一证据。重检受修改影响的后续节点、边和项目模块。

每轮保留简表：`问题 ID → 对应节点／段落 → 初学者产物中的错误 → 讲解改动 → 新检查 → 实际结果`。记录足够复查的事实与产物，不需要曝光内部思维过程。

## 防止模型偷用已有知识

初学者输出中的每个非日常概念、步骤、工具和推理规则，都必须追溯到已教内容。追溯不出即为“讲解缺口”，即使最终答案正确也不能通过。特别检查代码库调用、测试写法、数学变形、术语、读图方法与项目运行命令。

例如，只讲了递归的函数调用，却要求初学者突然实现异常处理和命令行解析，那么“写出正确程序”仍不足以说明讲解完整：这些技能要先教，或明确由运行框架提供，且核心知识相关逻辑必须由初学者亲手实现。

## 必须实际形成的初学者产物

- **自己的讲解**：不用范文解释定义、目的、本质机制和使用边界。
- **推导或过程**：给出关键中间步骤及其前提，能解释错误步骤为何错误。
- **知识网络**：遮住完成版图谱后，从已教内容重建完整节点清单、带类型的边表和可手绘图；覆盖当前范围的核心、细节、条件、对比、反例和应用，逐项核验方向与依据。
- **迁移题与错误诊断**：解决未展示过的案例，识别合理的错误做法，并在变化条件下说明方法何时失效。
- **独立项目**：按 [project-lab.md](project-lab.md) 从空白构造核心产物，展示接口、运行或推导过程、边界处理、验证和定位错误的方法。

针对完整主题，各知识分支应有相应检查。不能只验证中心概念却宣布全部细节通过。产物过大时拆为章节、子图和子项目，但最终保持范围矩阵的可追溯性。

## 严格通过门槛

以下全部满足，才可输出通过标记：

| 必需项 | 可检查的通过证据 |
| --- | --- |
| 覆盖完整 | 冻结后的范围矩阵中，每个核心、必需前置与必需细节均有讲解、来源状态和对应检查；无空项 |
| 提问闭环 | 当前范围内所有已发现问题都有修订和新检查证据；没有“暂不解释但默认掌握”的问题 |
| 复述与推导 | 初学者实际输出正确，无隐含未教前提、条件丢失或未经解释的步骤 |
| 网络重建 | 重建图、节点表、边表与核验后的参考结构逐项核对，目的、本质、逻辑、细节和关联均解释到位 |
| 独立迁移 | 新题、边界和错误诊断通过；不是只复现已教范例 |
| 项目完成 | 实际核心产物存在，要求与知识节点可追溯，全部必需验证项目有证据并通过 |
| 稳定复检 | 连续两轮使用不同挑战，无新增范围内问题、缺口或错误；其中一轮包含图谱重建，另一轮包含项目迁移或扰动 |

两轮是最低要求，不是次数上限。任何新问题、输出错误或失败项都立即重开对应缺口，修改教学，清零稳定轮数并继续。不能因为“已经循环很多次”就降低标准。

“没有问题”只指当前界定范围与检查中未发现问题，不是全球穷尽证明。AI 自我检查不能证明真实初学者一定理解；最终说明“模拟初学者检查通过”，真实用户仍通过独立作答、画图和做项目检验掌握。

## 没有收敛时

不得无限重复同一解释和同一测试。问题反复出现时改变讲法、补前置、换例子或检索关键证据；没有新证据或新修订的轮次不能算通过轮。

存在硬性时间、上下文、资料或工具限制时保存版本、产物、失败项和下一步，输出明确标记的“未通过／未验证的阶段成果”，不能作为最终合格结果。实际无法执行的必需测试一律记未验证；不将它们降为可选，不编造成功，也不声称会在回合结束后继续后台工作。

范围扩张应有记录：会影响核心正确性的内容必须加入；与既定目标无关的追问放入扩展或下一条线索并说明理由。不能用重新定义范围来隐藏失败。

## 面向用户的简短验收摘要

只呈现：检查范围；实际完成的轮数和不同挑战；代表性问题与教学纠正；初学者重建图／独立项目位置；执行证据；通过项、未通过项及未知项。保留真实用户练习与答案，方便用户自己检验。不得把预先设置的验收模板或计划写成已执行日志。
